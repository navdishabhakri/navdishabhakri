## 🤖 Agentic AI & RAG

### [Agentic AI Debugger](https://github.com/navdishabhakri/agentic-ai-debugger)
An autonomous agent that reads a failing test, finds the relevant code, writes a fix, **runs it to validate**, and opens a pull request. A second agent reviews PRs with inline comments. An MCP server lets Claude Desktop query the codebase directly.

- **Hybrid retrieval:** Tree-sitter AST chunking (8 languages) → BM25 + CodeBERT embeddings → Reciprocal Rank Fusion → Cohere rerank
- **Agent:** LangGraph, 5 nodes, persistent memory, retry logic
- **Evaluated with RAGAS:** faithfulness **0.77**, answer relevancy **0.84**, context recall **0.88**
- **Integrations:** GitHub Actions trigger on test failure, from-scratch MCP server
- `Python` `FastAPI` `LangGraph` `PostgreSQL + pgvector` `Cohere` `Groq` `Docker` `Railway`

### Marginalia
Turns any lecture (YouTube link or uploaded video) into timestamped notes, a synced player, a grounded chat, and a graded quiz. The whole AI pipeline is hand-built, with no LangChain or LlamaIndex.

- **Local-first:** whisper.cpp transcription and MiniLM embeddings run on-device
- **Two-pass note agent:** per-chunk Gemini function calling, then a bounded consolidation agent that merges, enriches, deletes and fills gaps
- **Human approval gate** before notes feed the quiz; hand-written cosine-similarity retrieval for chat; deterministic MCQ grading plus LLM-graded short answers
- **Live progress** over Server-Sent Events
- `TypeScript` `Node.js` `Express` `React` `Gemini` `yt-dlp` `ffmpeg`

## 📊 Machine Learning & Data Science

### Breast Cancer Diagnosis (Binary Classification)
Compared logistic regression, KNN, random forest, and SVM with a **recall-first** evaluation strategy, since a missed cancer costs far more than a false alarm.

- Stratified 5-fold CV, leakage-safe pipelines, held-out test set touched only at the end
- Feature engineering study: correlation pruning, PCA, SelectKBest
- Tuned SVM (RBF) with GridSearchCV optimizing recall: **CV recall 0.965**; **100% precision and 92.9% recall** on the test set
- `Python` `scikit-learn` `pandas` `Matplotlib` `Seaborn`

### Flight Delay Prediction
End-to-end classification workflow: cleaning, feature engineering, model comparison (Naive Bayes, decision tree, logistic regression), gains and lift charts.

- Logistic regression selected for best generalization (~**83%** validation accuracy)
- `Python` `scikit-learn` `pandas` `dmba`

### Toronto Crime Data Analysis
Exploratory and predictive analysis of Toronto Police open data from 2013 onward.

- **DBSCAN** for hotspot detection, **Apriori** association rules between crime types, decision trees for key predictors
- `Python` `pandas` `scikit-learn` `Seaborn`
